# Pingoose · 42 Intra Companion

GNOME Shell 42에서 42 Intra의 프로필, 프로젝트, 학습시간, 평가, 아젠다와 알림을 확인하는 확장입니다. 평가 슬롯 생성·닫기, 프로젝트 메모와 TODO, 평가 상대 채팅, 서비스 웹뷰를 제공합니다.

## 설치 및 로그인

42경산 교육용 PC에서 GNOME 데스크톱 터미널을 열고, 일반 사용자 계정으로 **sudo 없이** 실행합니다.

```sh
curl -fsSL https://raw.githubusercontent.com/Pingoose-42/pingoose_42_extension_main/main/install.sh | bash
```

설치에 쓸 소스는 자동으로 내려받습니다. 임시 폴더에서 설치를 마치면 내려받은 파일을 정리합니다.

브랜치, 태그 또는 커밋을 직접 고르려면 다음처럼 `--ref` 옵션을 붙입니다. `REF`를 원하는 이름이나 전체 커밋 SHA로 바꾸세요. 해당 커밋의 도우미를 실행하므로, 선택한 버전에도 이 설치기를 지원하는 코드가 있어야 합니다.

```sh
curl -fsSL https://raw.githubusercontent.com/Pingoose-42/pingoose_42_extension_main/main/install.sh | bash -s -- --ref REF
```

개발용 소스가 이미 있다면 프로젝트 루트에서 실행합니다. 이 경우에는 로컬 소스를 그대로 설치합니다.

```sh
./install.sh
```

필요 환경: GNOME Shell 42, GJS, GTK 3/4, WebKit2 4.0, Soup 2.4, Python 3 GI. 한 줄 설치에는 curl과 인터넷 연결도 필요합니다.

1. 설치 후 GNOME 세션을 다시 시작합니다. X11에서는 `Alt+F2` → `r` → Enter, Wayland에서는 로그아웃 후 재로그인합니다.
2. 확장을 활성화합니다.

   ```sh
   gnome-extensions enable pingoose@local
   ```

3. 탑바의 Pingoose를 열고 **Log in to 42 Intra**로 로그인합니다. Intra ID는 현재 PC 사용자명과 같아야 합니다.

설치·업데이트는 세션을 자동으로 재시작하지 않습니다. 설정 변경은 별도 Apply 안내가 있는 항목을 제외하면 즉시 반영됩니다.

## 메인 메뉴

| 영역 | 표시 및 동작 |
| --- | --- |
| Profile | 프로필 사진, 로그인, 레벨과 진행도, 포인트, Pace 및 기한 |
| My Projects | 프로젝트 목록. 클릭하면 TODO List / Note 패널 또는 프로젝트 웹페이지 열기 |
| Logtime | 학습시간 정보 |
| Evaluation Slots | 열린 슬롯 조회·생성·닫기 |
| Evaluation Info | 평가 역할, 프로젝트, 상대 로그인·좌석, 시작 시각과 남은 시간 |
| Agenda | 행사·시험 일정, 구독 상태와 피드백 필요 여부 |
| Notifications | 저장된 알림 확인 및 삭제 |
| 42 Services | 등록한 사이트를 서비스 패널과 웹뷰로 열기 |

Evaluation Slots, Evaluation Info, Agenda, Notifications는 제목 버튼으로 접고 펼칩니다. 항목 수는 제목 옆에 표시하며 0은 생략합니다. 펼친 제목 버튼과 42 Services 버튼은 강조색 배경으로 표시됩니다. 각 영역의 접기·펼치기 상태는 세션 재시작 후에도 유지됩니다.

메뉴를 다시 열면 **Create Slot과 아젠다 Details는 접힌 상태**로 시작합니다. 프로젝트·서비스 등 옆 패널은 최근에 연 패널이 메인 메뉴에 가장 가깝게 배치됩니다.

탑바에는 로그인 필요 상태, 피드백 대상 수 또는 새 알림 수가 표시됩니다. 카운트가 5를 넘으면 `5+`로 표시합니다. 일반 상태에서는 `42`를 표시합니다.

### ⋮ 메뉴

- **Visit 42 Intra**: Intra 웹뷰 열기.
- **Refresh**: 프로필·평가·아젠다·학습시간·슬롯을 다시 조회합니다. 숨기거나 삭제한 카드를 복원하지 않습니다. 갱신 중 로딩 아이콘, 완료 시 잠시 체크 표시가 나옵니다.
- **Settings**: 설정 창 열기.

## 평가 슬롯

열린 슬롯은 강조색 날짜·시간과 회색 길이 표시로 구성됩니다. 길이는 `(1 d 2 h 15 m)` 형식이며 0인 단위는 생략합니다.

| 조작 | 동작 |
| --- | --- |
| Refresh | 서버에서 열린 슬롯 다시 조회 |
| Create Slot | 수동 생성 카드 펼치기·접기 |
| 슬롯 옆 × | 해당 슬롯 닫기 |
| Close All Slots | 최신 서버 목록의 Available 슬롯 전체 닫기 |

### 수동 생성

Create Slot 카드에서 시작–종료 날짜·시·분을 ▲▼로 조절하고 하단 **Create**를 누릅니다.

- 시작 기본값은 현재보다 최소 30분 뒤인 가장 빠른 15분 경계입니다.
- 분은 `00 / 15 / 30 / 45` 단위로 변경합니다.
- 시작 시간을 변경하면 선택한 슬롯 길이를 유지하며 종료 시간도 이동합니다.
- 최소 길이는 15분입니다. 별도의 4시간 상한은 없으며, **종료는 현재부터 7일 이내**여야 합니다.
- 생성 직전 서버 목록과 겹침을 검사합니다. 기존 슬롯 끝에 이어 붙이는 시간대는 허용합니다.
- 겹치면 충돌한 슬롯의 시간대를 빨간색으로 표시합니다. 실패 시 생성 카드를 유지하고, 성공하면 닫습니다.
- 생성 후 서버 목록을 다시 읽으므로 서버에서 연결된 슬롯은 합쳐진 시간 범위로 표시됩니다.

평가가 매칭된 구간은 빨간 Evaluation Matched 항목으로 표시하며 개별 닫기 버튼을 제공하지 않습니다. 분할된 열린 구간은 각각 표시합니다. Close All Slots는 예약된 평가를 취소하는 기능이 아닙니다. 닫기 요청 후 남아 있는 슬롯도 다시 확인합니다. 생성·삭제의 최종 수락 여부는 Intra 서버가 결정합니다.

## 평가 정보와 채팅

평가 카드에는 역할, 프로젝트, 상대 로그인과 좌석, **Starts 날짜·시간**, 괄호 안의 남은 시간 또는 경과 시간이 표시됩니다. 날짜·시간은 다크 테마에서 흰색, 라이트 테마에서 검은색으로 강조합니다.

평가자 카드는 시작 시각이 지난 뒤 정상 조회된 평가 목록에서 사라지면 자동으로 제거하며, 재로그인 직후에도 확인합니다. 피평가자 카드는 프로젝트 페이지에서 피드백 버튼을 확인한 뒤 같은 평가의 버튼이 사라지면 자동으로 제거합니다. 평가 목록은 기본 10초, 피드백 버튼은 프로젝트별 약 10초 간격으로 확인하며 서버 요청 제한을 따릅니다. 조회 실패나 불확실한 상태에서는 카드를 유지하고 기존 수동 확인을 사용할 수 있습니다. 시작 전에 정상 서버 응답에서 매칭이 사라지면 **Evaluation Missing**을 표시하고 채팅을 비활성화합니다. 통신 실패만으로 Missing 처리하지 않으며, 매칭이 다시 조회되면 복구합니다. Missing 카드의 Remove Evaluation은 Yes로 삭제하거나 Later로 보류할 수 있습니다.

### 평가 상대 채팅

- 평가 시작 전 마지막 15분 동안 사용할 수 있습니다. 상대 상세 정보는 이 구간에서 약 5초 간격으로 갱신하며 서버의 요청 제한을 우선합니다.
- 좌석이 확인되면 백그라운드로 호환 클라이언트의 응답을 확인합니다. 이 확인으로 메시지·알림·대화창을 만들지는 않습니다.
- 평가 정보와 좌석 검증을 통과한 상대에게만 **Cluster Chat** 버튼을 표시합니다. 같은 평가·상대·좌석·시작 시각에 대해 무응답 시 반복 연결하지 않습니다.
- 상대 좌석이 바뀌면 새 좌석을 확인합니다. 연속된 좌석 미확인이나 오래된 확인 정보는 연결을 제한합니다.
- 평가 시작 시 채팅 송수신을 중지하고 해당 평가의 연결과 임시 대화 기록을 정리합니다. 매칭 소실·로그아웃·직접 Disconnect도 정리 사유입니다.

채팅은 캠퍼스 좌석 PC 사이의 TCP 통신이며 상대 PC에도 호환 수신 기능이 필요합니다. TLS 암호화나 사용자 서명 인증은 제공하지 않습니다.

## 아젠다

카드는 제목, 시작 날짜, 남은 시간을 표시합니다. 남은 시간의 0인 단위는 생략하며, 시작 후에는 진행·종료 상태를 표시합니다.

- **Subscribed**: 구독 중이면 제목 옆에 옅게 표시합니다.
- **Feedback required**: Details 하단의 Visit Agenda Page로 해당 일정 페이지를 열 수 있습니다. 서버의 미작성 피드백 목록(`/events/unfeedbacked`)에 포함되면 Subscribed 대신 빨간색으로 표시합니다.
- **Details**: 전체 일정, 장소(제공된 경우), 구독 인원/정원, 취소 제한 시각과 본문을 펼칩니다. 본문은 일반 텍스트로 전체 표시하며 별도의 See more 버튼은 없습니다.
- **Subscribe / Unsubscribe**: Details 하단에서 실제 Intra 신청 상태를 변경합니다. 요청 전에 최신 정원·구독 ID·취소 기한을 확인하고 결과를 다시 조회합니다.
- **⋮ → Hide Agenda**: 서버 구독을 변경하지 않고 패널에서 해당 카드를 숨깁니다.

신청·취소 버튼은 시작 전 일정과 확인 가능한 상태를 기준으로 제공됩니다. 정원, 대기자 상태, 취소 기한 등에 따라 버튼이 없을 수 있습니다. 대기자 신청과 행사 피드백 작성은 Intra 웹사이트에서 진행합니다. 시험은 세션 구독과 별도로 시험 프로젝트 등록도 필요합니다.

숨긴 아젠다는 Refresh·재로그인·세션 재시작으로 복원되지 않습니다. **Settings → General → Agenda Reset**으로 숨김 기록을 지우고 현재 서버 목록을 다시 불러올 수 있습니다.

## 프로젝트 메모와 TODO

My Projects의 프로젝트를 클릭하면 **TODO List / Note** 패널이 열립니다. **My Projects 제목**을 누르면 특정 과제에 속하지 않는 공용 메모 패널이 열리며, 이 패널에는 Visit Project Page 버튼이 없습니다.

- Add Note로 제목과 내용을 입력하고 Save로 저장합니다.
- TODO는 직접 줄바꿈한 줄마다 별도 항목으로 저장하며 각각 체크·수정·삭제할 수 있습니다. 긴 한 줄의 자동 줄바꿈은 하나의 항목으로 유지됩니다.
- Edit로 수정하고 Visit Project Page로 프로젝트 웹페이지를 엽니다.
- 저장된 항목은 프로젝트·로그인 계정별로 구분하며 생성일 오름차순으로 표시합니다.
- 저장하지 않은 초안은 실행 중인 확장의 메모리에만 있으므로 로그아웃·세션 재시작 전에 Save가 필요합니다.

## 알림

평가 매칭·리마인더·좌석 정보, 새 아젠다, 채팅 메시지에 대한 시스템 알림을 제공합니다. 알림 클릭 시 메뉴를 열며 채팅 알림은 해당 대화로 연결합니다.

알림 카드는 × 또는 Clear All로 삭제할 때까지 저장됩니다. 메뉴를 열면 읽음 처리합니다. 시스템 알림을 꺼도 카드와 읽지 않은 메시지는 유지됩니다. 평가 카드 제거와 알림 카드 삭제는 별개입니다.

## 42 Services와 웹뷰

42 Services를 누르면 등록한 사이트 카드가 있는 옆 패널이 열립니다. 기본 사이트는 [SUBAK](https://subak.site/)과 [PeerFinder](https://peerfinder.org/)입니다. 사이트 카드는 미리보기 이미지 또는 기본 웹 아이콘을 표시합니다.

Settings → 42 Services에서 HTTPS 사이트를 최대 30개까지 추가·수정·삭제하거나 기본 목록을 복원할 수 있습니다. 기능을 끄면 열려 있는 서비스 웹뷰도 닫힙니다.

웹뷰 앱 이름은 **Pingoose WebView**입니다. Intra·프로젝트·서비스 창에는 뒤로, 앞으로, 새로고침과 F5를 제공합니다. 최초 로그인 창은 탐색 버튼 없이 열리며 로그인 성공 후 자동으로 닫힙니다. 서비스 창은 Intra 웹뷰 컨텍스트를 공유하고 도메인별 쿠키 규칙을 따릅니다.

### Notifications

| 항목 | 기본값 / 범위 |
| --- | --- |
| Evaluation matches, reminders and locations | 켜짐 |
| New agenda events | 켜짐 |
| Cluster Chat messages | 켜짐 |
| Warn about slots and evaluations before logout | 켜짐. PC 로그아웃 시 열린 슬롯·예정된 평가·피드백 완료 미확인 평가 안내 |
| Banner duration (seconds) | 4초, 0~120초. 0은 직접 닫을 때까지 유지 |
| Screen flash (0 = Off) | 1회, 0~5회 |

로그아웃 확인창은 열린 슬롯, 예정된 평가, 피드백 완료 확인이 남은 지난 평가를 별도 목록으로 표시합니다. 지난 평가는 핑구스에서 완료 확인하지 않은 카드 기준이며 서버의 실제 미작성 여부를 확정하는 표시는 아닙니다. 프로젝트명·역할·상대 닉네임·시작 시간을 함께 표시합니다. 평가에는 서버가 제공한 프로젝트명과 시간을 표시하며, 슬롯 닫기를 선택해도 예약된 평가는 유지됩니다. 로그아웃 경고를 꺼도 서버 슬롯이 자동으로 닫히지는 않습니다.

## 업데이트

PC에 로그인한 뒤 확장이 시작될 때 업데이트를 한 번 확인합니다. 기본 확인 대상은 GitHub 저장소의 `main` 브랜치이며, 설치할 때 `--ref`로 다른 브랜치나 태그를 골랐다면 그 참조를 계속 사용합니다. 커밋 SHA를 지정했다면 해당 커밋을 유지합니다.

**Auto Update는 기본으로 켜져 있어** 새 버전이 확인되면 바로 설치합니다. 이 설정을 끄면 알림의 **Yes / No**로 설치 여부를 선택할 수 있습니다. 설치 기록이 없는 기존 설치본에는 현재 확인한 최신 버전을 설치하도록 안내합니다.

업데이트는 확인한 커밋의 소스 압축 파일을 받아 설치합니다. 작업이 끝나면 임시 파일을 정리하고, 설치에 성공하면 알림 카드에 변경 내용을 표시합니다. 완료 알림을 받은 뒤 GNOME Shell을 다시 시작하거나 로그아웃 후 로그인하면 새 버전이 적용됩니다. 업데이트할 때도 인터넷 연결이 필요합니다.

확장을 껐다 켜거나 GNOME Shell을 다시 시작해도 같은 로그인 세션에서는 자동 확인을 반복하지 않습니다. 바로 다시 확인하려면 **General → Check for Updates**를 누르세요. 업데이트를 거절했거나 설치에 실패한 경우에도 이 메뉴에서 다시 확인할 수 있습니다.

업데이트를 받을 저장소와 브랜치를 바꾸려면 `~/.config/pingoose/update.json`에 아래 형식으로 저장합니다. 이 파일의 설정을 설치할 때 정한 값보다 먼저 적용합니다.

```json
{
  "repository": "https://github.com/Pingoose-42/pingoose_42_extension_main",
  "branch": "main"
}
```

`repository`에는 GitHub 공개 저장소의 HTTPS 주소를 넣습니다. 저장소나 브랜치를 바꾸면 다음 업데이트 확인부터 새 설정을 사용합니다.

실제로 설치한 커밋은 확장 디렉터리의 `config/installed.json`에 기록합니다. 업데이트 확인과 설치 결과는 `~/.local/state/pingoose/updates/state.json`에 저장합니다. XDG 환경변수를 지정했다면 그 경로를 사용합니다.

## 데이터 보관과 제거

설정은 GSettings에, 사용자 데이터는 전용 XDG 디렉터리에 저장합니다.

| 데이터 | 기본 위치 |
| --- | --- |
| 카드·알림·메모 등 상태 | `~/.local/state/pingoose/` |
| 프로젝트 메모·TODO | `~/.local/state/pingoose/notes/projects.json` |
| 웹뷰 쿠키 | `~/.local/share/pingoose/cookies.sqlite` |
| 웹뷰 사이트 데이터 | `~/.local/share/pingoose/profile/` |
| 캐시 | 확장 전용 XDG cache 및 웹뷰 데이터 디렉터리 |

XDG 환경변수를 지정했다면 해당 경로를 사용합니다. 일반 Intra 로그아웃은 인증 정보를 정리하지만 저장된 메모·평가 기록·알림 파일은 보존합니다. 같은 계정으로 다시 로그인하면 저장된 카드를 복원하며 복원만으로 시스템 알림을 재발송하지 않습니다. 평가 채팅에는 별도의 만료 정책이 적용됩니다.

**Reset All Data**는 메모·TODO, 채팅 데이터, 알림, 프로필·이미지 캐시, 웹뷰 로그인 데이터와 사용자 설정을 초기화합니다. 완료 여부는 General에서 확인합니다. 확장 제거만으로는 사용자 데이터와 설정이 삭제되지 않으므로 완전 삭제하려면 초기화를 완료한 뒤 확장을 제거합니다.

## 개발 및 검증

코드의 진입점, 기능별 파일 위치와 검증 방법은 [코드 구조와 개발 안내](docs/ARCHITECTURE.md)를 참고하세요.

프로젝트 루트에서 실행합니다.

```sh
bash src/scripts/test.sh
bash src/scripts/test.sh --sockets
bash src/scripts/package.sh /tmp/pingoose-release
```

기본 검증은 JavaScript 문법과 회귀 테스트, 설치·업데이트용 Python 테스트, 설정 스키마를 확인합니다. `--sockets`는 GJS 로컬 채팅 통신 테스트도 실행합니다. 실제 GNOME 화면 배치와 다른 좌석 PC 간 통신은 별도 확인이 필요합니다. 배포 패키지에는 실행 소스·에셋·스키마가 포함되며 테스트·개인 인증 데이터는 포함하지 않습니다.
